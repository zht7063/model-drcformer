# DRCFormer 环境配置补充说明

本文档记录从零搭建 py310 环境时可能遇到的坑及解决方案，作为 `环境部署方案.md` 的补充。

---

## 一、安装顺序建议

推荐按以下顺序安装，可避免依赖冲突：

1. 创建 conda 环境：`conda create -n py310 python=3.10 -y`
2. 安装 PyTorch（GPU cu121）：`pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121`
3. 安装 torch-scatter（见下文）
4. 安装 pydensecrf（见下文）
5. 安装 fast-slic（见下文）
6. 安装其余依赖：`pip install -r requirements.txt`（需跳过已特殊处理的包）

---

## 二、常见坑及解决方案

### 2.1 torch-scatter

**现象**：`pip install -r requirements.txt` 报错：

```
ERROR: Could not find a version that satisfies the requirement torch-scatter==2.1.2+pt25cu121
```

**原因**：PyPI 上没有带 `+pt25cu121` 后缀的预编译包，需从 PyG 官方 wheel 源安装。

**解决**：

```bash
pip install torch-scatter -f https://data.pyg.org/whl/torch-2.5.0+cu121.html
```

---

### 2.2 pydensecrf

**现象**：
- `pydensecrf==1.0` 在 PyPI 不存在（仅有 1.0rc1/rc2/rc3）
- 从源码 `pip install pydensecrf` 时，Cython 编译报错：`'eigen.pxd' not found`、`'c_MatrixXf' is not a type identifier`

**原因**：pydensecrf 源码与新版 Cython 存在兼容性问题，pip 从源码编译易失败。

**解决**：使用 conda-forge 提供的预编译版本：

```bash
conda install -c conda-forge pydensecrf -y
```

---

### 2.3 fast-slic

**现象**：`pip install fast-slic` 报错：

```
distutils.errors.DistutilsError: Command '...python -m pip...' returned non-zero exit status 1
# 或 No module named pip（发生在 build isolation 环境内）
```

**原因**：fast-slic 需要 Cython 编译，在 PEP 517 隔离构建环境中可能找不到 pip/cython。

**解决**：

```bash
pip install cython
pip install fast-slic --no-build-isolation
```

---

### 2.4 网络/下载慢

**现象**：pip/conda 下载速度很慢或超时。

**解决**：如有本地代理（如 HTTP 7890、SOCKS5 7891），可先执行 `proxy_on` 再安装：

```bash
proxy_on
pip install -r requirements.txt
```

## 三、快速复现命令（含坑的修复）

```bash
# 1. 创建并激活环境
conda create -n py310 python=3.10 -y
conda activate py310

# 2. PyTorch
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121

# 3. torch-scatter（单独安装）
pip install torch-scatter -f https://data.pyg.org/whl/torch-2.5.0+cu121.html

# 4. pydensecrf（conda 安装）
conda install -c conda-forge pydensecrf -y

# 5. fast-slic（需先装 cython，且 --no-build-isolation）
pip install cython
pip install fast-slic==0.4.0 --no-build-isolation

# 6. 其余依赖（可手动列举或修改 requirements.txt 后执行）
pip install timm einops scipy scikit-learn scikit-image pandas opencv-python opencv-python-headless matplotlib tqdm loguru pyyaml tensorboard gdown huggingface-hub safetensors regex ftfy cmapy visdom websocket-client wcwidth
```
