# DRCFormer 环境配置补充说明

本文档记录从零搭建 py310 环境时可能遇到的坑及解决方案，作为 `环境部署方案.md` 的补充。

> **推荐**：直接使用 `prepare_env/install.sh` 一键安装，已内置下列踩坑修复。详见 [`prepare_env/README.md`](../prepare_env/README.md)。

---

## 一、安装顺序建议

**推荐（一键）**：

```bash
cd prepare_env
bash install.sh
conda activate py310
```

**手动分步**（排错用，与 `install.sh` 逻辑一致）：

1. `conda env create -f prepare_env/conda-env.yml`（含 pydensecrf、pytorch-cuda）
2. 安装 PyTorch（GPU cu121）
3. 安装 torch-scatter（见下文）
4. 安装 fast-slic（见下文）
5. 安装其余依赖：`pip install -r`（过滤后的 `prepare_env/pip.lock`）

---

## 二、常见坑及解决方案

### 2.1 torch-scatter

**现象**：直接 `pip install` 报错：

```
ERROR: Could not find a version that satisfies the requirement torch-scatter==2.1.2+pt25cu121
```

**原因**：PyPI 上没有带 `+pt25cu121` 后缀的预编译包，需从 PyG 官方 wheel 源安装。

**解决**：

```bash
pip install torch-scatter==2.1.2+pt25cu121 \
  -f https://data.pyg.org/whl/torch-2.5.0+cu121.html
```

---

### 2.2 pydensecrf

**现象**：
- `pydensecrf==1.0` 在 PyPI 不存在（仅有 1.0rc1/rc2/rc3）
- 从源码 `pip install pydensecrf` 时，Cython 编译报错：`'eigen.pxd' not found`、`'c_MatrixXf' is not a type identifier`

**原因**：pydensecrf 源码与新版 Cython 存在兼容性问题，pip 从源码编译易失败。

**解决**：使用 conda-forge 提供的预编译版本（`prepare_env/conda-env.yml` 已包含）：

```bash
conda install -c conda-forge pydensecrf -y
```

---

### 2.3 fast-slic

**现象**：`pip install fast-slic` 报错：

```
distutils.errors.DistutilsError: Command '...python -m pip...' returned non-zero exit status 1
# 或 No module named pip（发生在 build isolation 环境内）
```

**原因**：fast-slic 需要 Cython 编译，在 PEP 517 隔离构建环境中可能找不到 pip/cython。

**解决**：

```bash
pip install Cython==3.2.4
pip install fast-slic==0.4.0 --no-build-isolation
```

---

### 2.4 网络/下载慢

**现象**：pip/conda 下载速度很慢或超时。

**解决**：如有本地代理（如 HTTP 7890、SOCKS5 7891），可先执行 `proxy_on` 再安装：

```bash
proxy_on
cd prepare_env && bash install.sh
```
