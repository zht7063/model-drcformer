# DRCFormer 项目环境部署方案

## 零、复现环境前必须确认的“需要手动做/依赖硬件环境修改”的点（必读）

本项目依赖 PyTorch + CUDA。**能否直接安装预编译 wheel、是否会触发本机编译、以及该装哪种版本**，主要取决于你的 GPU / 驱动 / CUDA 版本。

### 0.1 先做 3 个检查（按输出选择分支）

```bash
# 1) 是否有 NVIDIA GPU / 驱动是否正常
nvidia-smi

# 2) （可选）是否有 nvcc（只有你计划“本机编译 CUDA 扩展”才需要）
nvcc --version

# 3) 检查 PyTorch 期望的 CUDA（装完 PyTorch 后再看）
python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
```

### 0.2 选择安装分支（你必须选一个）

- **分支 A：GPU + CUDA（推荐；与当前 py310 环境一致）**
  - 适用：`nvidia-smi` 正常，且驱动满足 CUDA 12.1（或更高）
  - 关键点：`requirements.txt` 当前锁定了 `torch==2.5.1+cu121` 等版本
- **分支 B：CPU（不推荐；可能无法跑完整流程/速度很慢）**
  - 适用：没有 NVIDIA GPU，或 CUDA/驱动不满足要求
  - 关键点：不要直接使用 `requirements.txt` 里的 `+cu121` 版本；需按 2.4 节改装 CPU 版 PyTorch，再安装其余依赖

## 一、系统要求

### 1.1 硬件要求
- **GPU**: 支持 CUDA 12.1 的 NVIDIA GPU（推荐显存 ≥ 8GB）
- **内存**: ≥ 16GB RAM
- **存储**: ≥ 50GB 可用空间（用于数据集和模型权重）

### 1.2 软件要求
- **操作系统**: Linux (Ubuntu 18.04+ 推荐)
- **CUDA**: 12.1 或更高版本
- **cuDNN**: 9.1.0 或兼容版本
- **Python**: 3.10.x
- **Conda**: 最新版本

## 二、环境部署步骤

### 2.1 安装 Conda（如未安装）

```bash
# 下载 Miniconda（推荐）或 Anaconda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh

# 重新加载 shell 配置
source ~/.bashrc
```

### 2.2 创建 Conda 环境

```bash
# 创建 Python 3.10 环境
conda create -n py310 python=3.10 -y

# 激活环境
conda activate py310
```

### 2.3 安装 CUDA 相关依赖（通过 Conda）

```bash
# 安装 CUDA Toolkit 和 cuDNN（CUDA 12.1）
conda install -c nvidia cuda-toolkit=12.1 -y
conda install -c conda-forge cudnn=9.1.0 -y

# 或者使用 pytorch 官方 channel 安装 CUDA 支持
conda install pytorch-cuda=12.1 -c pytorch -c nvidia -y
```

### 2.4 安装 PyTorch 及相关库

```bash
# 分支 A：GPU + cu121（推荐，与 requirements.txt 一致）
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121

# 分支 B：CPU（如果没有 NVIDIA GPU；注意：不要用 requirements.txt 里的 +cu121 版本）
# pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cpu

# （可选）你也可以使用 conda 安装 GPU 版 PyTorch：
# conda install pytorch torchvision torchaudio pytorch-cuda=12.1 -c pytorch -c nvidia -y
```

### 2.5 安装编译工具和系统依赖

**重要**: 以下包可能需要编译，需要先安装编译工具：

```bash
# 安装编译工具（Ubuntu/Debian）
sudo apt-get update
sudo apt-get install -y build-essential cmake git
sudo apt-get install -y python3-dev python3-pip

# 或者使用 conda 安装编译工具
conda install -c conda-forge cmake make gcc_linux-64 gxx_linux-64 -y
```

### 2.6 安装项目依赖

```bash
# 进入项目根目录
cd /data/user/tyb/drcformer

# 分支 A：GPU+cu121：直接安装 requirements.txt（推荐）
pip install -r requirements.txt

# 分支 B：CPU：不要直接装 requirements.txt（里面锁了 +cu121）
# 你需要“先按 2.4 装 CPU 版 PyTorch”，再安装其余依赖（示例）：
# pip install timm==1.0.20 einops==0.8.1 numpy==1.26.4 scipy==1.15.3 scikit-learn==1.7.2 scikit-image==0.25.2 pandas==2.3.3 pillow==12.0.0 \
#   opencv-python==4.11.0.86 opencv-python-headless==4.12.0.88 matplotlib==3.10.6 fast-slic==0.4.0 pydensecrf==1.0 \
#   tqdm==4.67.1 loguru==0.7.3 pyyaml==6.0.3 tensorboard==2.19.0 gdown==5.2.1 huggingface-hub==0.35.3 safetensors==0.7.0 \
#   regex==2026.1.15 ftfy==6.1.1 cmapy==0.6.6 visdom==0.2.4 websocket-client==1.9.0 wcwidth==0.2.14
# （说明）CPU 分支下 torch-scatter / nvidia-* 这类 CUDA 相关包一般不装；如确需请按 5.5 节排查并自行调整。
```

**注意**: 如果遇到编译错误，请参考"五、常见问题排查"中的编译问题解决方案。

### 2.7 验证安装

```bash
# 验证 Python 版本
python --version  # 应显示 Python 3.10.x

# 验证 PyTorch 和 CUDA
python -c "import torch; print(f'PyTorch: {torch.__version__}'); print(f'CUDA available: {torch.cuda.is_available()}'); print(f'CUDA version: {torch.version.cuda}')"

# 验证主要依赖包
python -c "import timm; import numpy; import cv2; import matplotlib; print('All core packages imported successfully')"

# 验证两个“常见会触发编译/ABI 匹配”的包（建议）
python -c "import pydensecrf; print('pydensecrf OK')"
python -c "import torch_scatter; print('torch_scatter OK')"
```

## 五、常见问题排查

### 5.1 CUDA 不可用

```bash
# 检查 CUDA 驱动
nvidia-smi

# 检查 PyTorch CUDA 支持
python -c "import torch; print(torch.cuda.is_available())"

# 如果不可用，重新安装 PyTorch
pip uninstall torch torchvision torchaudio
pip install torch==2.5.1 torchvision==0.20.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
```

### 5.2 依赖冲突

```bash
# 创建全新的环境
conda deactivate
conda remove -n py310 --all -y
conda create -n py310 python=3.10 -y
conda activate py310

# 重新安装
pip install -r requirements.txt
```

### 5.3 内存不足

- 减小 batch size
- 使用梯度累积
- 使用混合精度训练

### 5.4 超像素相关错误

```bash
# 确保 fast-slic 正确安装
pip install --upgrade fast-slic

# 检查 pydensecrf
pip install --upgrade pydensecrf
```

### 5.5 编译相关错误（重要）

以下包可能需要编译，如果安装失败，请按以下步骤处理：

#### 5.5.1 pydensecrf 编译问题

`pydensecrf` 包含 C++ 代码，需要编译。如果安装失败：

```bash
# 方法1: 确保已安装编译工具
sudo apt-get install -y build-essential cmake python3-dev

# 方法2: 从源码安装（如果 pip 安装失败）
git clone https://github.com/lucasb-eyer/pydensecrf.git
cd pydensecrf
pip install .

# 方法3: 使用预编译的 wheel（如果可用）
pip install pydensecrf --no-build-isolation
```

**常见错误**:
- `error: Microsoft Visual C++ 14.0 or greater is required` (Windows): 安装 Visual Studio Build Tools
- `fatal error: Python.h: No such file or directory`: 安装 `python3-dev`
- `cmake: command not found`: 安装 `cmake`

#### 5.5.2 torch-scatter 编译问题

`torch-scatter` 包含 CUDA 扩展，需要编译。如果安装失败：

```bash
# 方法1: 确保 PyTorch 已正确安装
python -c "import torch; print(torch.__version__)"

# 方法2: 从源码安装（需要匹配的 CUDA 版本）
pip install torch-scatter --no-cache-dir

# 方法3: 使用预编译版本（推荐）
pip install torch-scatter -f https://data.pyg.org/whl/torch-2.5.0+cu121.html
```

**常见错误**:
- `CUDA not found`: 确保 CUDA 和 PyTorch CUDA 版本匹配
- `nvcc: command not found`: 安装 CUDA Toolkit
- `RuntimeError: CUDA error`: 检查 CUDA 驱动版本

#### 5.5.3 其他可能需要编译的包

以下包通常有预编译版本，但在某些情况下可能需要编译：

- `numpy`: 通常有预编译 wheel，编译需要 BLAS/LAPACK
- `scipy`: 通常有预编译 wheel，编译需要 Fortran 编译器
- `opencv-python`: 通常有预编译版本，但 `opencv-python-headless` 可能需要编译

**通用解决方案**:

```bash
# 安装所有编译依赖（Ubuntu/Debian）
sudo apt-get install -y \
    build-essential \
    cmake \
    git \
    python3-dev \
    python3-pip \
    libatlas-base-dev \
    gfortran \
    libjpeg-dev \
    libpng-dev \
    libtiff-dev \
    libavcodec-dev \
    libavformat-dev \
    libswscale-dev \
    libv4l-dev \
    libxvidcore-dev \
    libx264-dev \
    libgtk-3-dev \
    libcanberra-gtk-module \
    libcanberra-gtk3-module

# 如果仍然失败，尝试使用 conda 安装（通常有预编译版本）
conda install -c conda-forge numpy scipy opencv -y
```

## 七、环境备份与恢复

### 7.1 导出环境配置

```bash
# 导出 conda 环境
conda env export -n py310 > environment.yml

# 导出 pip 包列表
pip freeze > requirements_full.txt
```

### 7.2 强烈建议：用“锁定文件”复现（比只靠 requirements.txt 更稳）

`requirements.txt` 是“核心依赖清单”；但真正跨机器复现时，**CUDA/PyTorch/扩展包**经常受硬件与系统库影响。建议你在“已跑通”的机器上保留：

- `environment.yml`：偏 conda 的快照（含 channel 与版本）
- `requirements_full.txt`：偏 pip 的快照（更细，但也更“机器绑定”）

当你需要在新机器复现时，优先尝试：

```bash
conda env create -f environment.yml
conda activate py310
```

### 7.2 从备份恢复

```bash
# 从 environment.yml 创建环境
conda env create -f environment.yml

# 或从 requirements.txt 安装
conda create -n py310 python=3.10 -y
conda activate py310
pip install -r requirements.txt
```

## 九、可能需要编译的包清单

以下包在 requirements.txt 中，**可能需要编译工具**才能安装：

| 包名 | 是否需要编译 | 说明 | 解决方案 |
|------|------------|------|---------|
| `pydensecrf` | ✅ **是** | 包含 C++ 代码 | 需要 `cmake`, `g++`, `python3-dev` |
| `torch-scatter` | ✅ **是** | 包含 CUDA 扩展 | 需要匹配的 CUDA 和 PyTorch 版本 |
| `numpy` | ⚠️ 可能 | 通常有预编译版本 | 如有问题，使用 conda 安装 |
| `scipy` | ⚠️ 可能 | 通常有预编译版本 | 如有问题，使用 conda 安装 |
| `opencv-python` | ⚠️ 可能 | 通常有预编译版本 | 如有问题，使用 conda 安装 |
| `regex` | ⚠️ 可能 | 包含 C 扩展 | 通常有预编译版本 |
| `pillow` | ⚠️ 可能 | 包含 C 扩展 | 通常有预编译版本 |

**推荐安装顺序**:
1. 先安装编译工具（见 2.5 节）
2. 安装 PyTorch（通常有预编译版本）
3. 安装其他依赖（pip 会自动选择预编译版本）
4. 如果某个包安装失败，参考 5.5 节的解决方案

## 十、注意事项

1. **CUDA 版本兼容性**: 确保系统 CUDA 驱动版本 ≥ 12.1
2. **Python 版本**: 严格使用 Python 3.10，其他版本可能导致兼容性问题
3. **编译工具**: 确保安装 `build-essential`, `cmake`, `python3-dev` 等编译工具
4. **路径配置**: 确保数据集和预训练权重路径正确
5. **权限问题**: 确保对输出目录有写权限
6. **磁盘空间**: 训练过程会产生大量中间文件，确保有足够空间
7. **编译时间**: `pydensecrf` 和 `torch-scatter` 的编译可能需要几分钟时间
